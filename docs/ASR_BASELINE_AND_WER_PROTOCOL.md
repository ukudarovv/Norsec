# ASR baseline, протокол WER/CER и публикация аудиоданных (KZ/RU)

## Выбор базовых моделей

| Вариант | Когда использовать | Комментарий |
|---------|-------------------|-------------|
| **OpenAI Whisper** (`openai/whisper-*`) | Универсальный baseline, смешение языков и шум | Удобно хостить inference из Hugging Face; для edge нужен размер модели и квантизация |
| **NVIDIA NeMo RU FastConformer** | Точный русский офлайн-серверный сценарий | Часто живёт отдельно от Hub; связать README с точным artifact |
| **`nvidia/stt_kk_ru_fastconformer_hybrid_large`** | Критичен code-switch KK↔RU | Рекомендуем как целевой Hub-ориентированный маршрут после пилота |
| **Vosk** | Ограниченное edge-железо, полный офлайн | Качество на дальнем микрофоне ограничено; не публиковать аудио субъектов |

Выбор после пилота: сравниваем Whisper-small/medium против NeMo KK+RU на **вашем доменном dev-set**.

## Протокол оценки (WER/CER и срезы)

1. **Нормализация текста**  
   Приведите эталон и гипотезу к одному регистру (опционально), удалите пунктуацию по общему правилу или сохраните для казахского диакритики **осознанный** режим и зафиксируйте его в протоколе.

2. **Срезы**  
   Отчёт отдельно по языку: `ru_only`, `kz_only`, `mixed`, плюс `high_noise`, `near_field`, если размечены.

3. **Метрики**  
   - **WER**: слова для RU/KZ (учитывать, что некоторые токенизации различают слитные формы — зафиксировать токенайзер).  
   - **CER**: для фраз короткой длины и для stress-тестов сленга.

4. **Калибровка чанков**  
   Секции 0.5–2 с с наложением; не штрафуйте дважды общий хвост, если считаете по конкатенации.

## Политика публикации аудио на Hugging Face

- **Не** выкладывать сырые школьные/рабочие записи без отдельного правового решения и минимизации.
- По умолчанию: только **выделенные** фрагменты с размыванием голоса / агрессивным понижающим псевдонимизацией — по заключению DPO-подобной роли.
- Для воспроизводимости: храните **fingerprints фикстур**, глобально уникальный `scenario_id`, список микрофонов только на уровне класса («lapel_far»), без серийников.
- **Gated** dataset на Hub как основной паттерн для доменной речи.

## Рекомендуемые следующие команды после появления dev-set

1. Снимите baseline WER на Whisper-medium и на `nvidia/stt_kk_ru_fastconformer_hybrid_large` (локально через NeMo toolkit или ONNX).  
2. Fine-tune/LoRA на доменном train (после согласования PDn); зафиксируйте чекпоинт версией в карточке модели и в `fusion` JSON контракте (`model_version`).  
3. Если обучение нужно масштабировать в облаке Hugging Face, оцените **Jobs** по skill `huggingface-jobs`: таймаут, GPU, сохранённый artifact.
